## 1. 概要

### 1-1. 目的
様々な偉業を残した偉人たちの顔画像のデータに対してラベリングを行い、顔画像のデータをもとにその顔の人間がどのような偉業を残すか予想することが出来るWebアプリケーションの作成。

### 1-2. 背景
世間には顔から万引きを行いそうな人間を予想したり、健康状態を推測するといったその人間の「現状」にフォーカスしたAIはよく見受けられるが、占いのように「未来」にフォーカスしたAIがあったとしたら面白いのではないかと考えたため、作成するに至った。

## 3. 非機能要件

- レスポンス時間は10分以内とする（画像アップロードから結果表示まで）
- 画像データは全てインターネット上のものとする
- 保存先は最終的には大学のサーバーに保存する（※実装時にHugging Face Spacesへ変更）
- 各大分類のカテゴリ分けには一つのカテゴリあたり60枚以上の学習データを用いる
- 小分類に関しての最低学習枚数は指定しない

## 4. API設計

### 4-1. 必要なAPIのエンドポイント
- フロントからバックに画像データ（顔画像）を送信する
- バックからフロントにテキストデータ（カテゴリ分けの結果）を送信する

### 4-2. リクエスト側の型とJSの例

```
[Http]
POST /predict
Content-Type: multipart/form-data
```

```javascript
const formData = new FormData();
formData.append("file", fileInput.files[0]);

fetch("/predict", {
  method: "POST",
  body: formData
});
```

### 4-3. レスポンス側のJSON形式の例（計画時点）

```json
{
  "prediction": "nobel",
  "subprediction": "nobel_peace"
}
```

大分類が「ノーベル賞受賞者」で小分類が「ノーベル平和賞受賞者」だった場合。

> 実装時の注記: 小分類予測を見送ったため、実際のレスポンス形式は `{"prediction": string, "probability": float, "category_id": int}` に変更されています。詳細は [README「7. API仕様」](../README.md#7-api仕様) を参照してください。
